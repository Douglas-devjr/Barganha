# Design / Protótipo

Solte aqui o design do app (feito no Claude Design) para o Claude Code ler.

## Como organizar
- **Telas (imagens):** salve em `design/screens/` como PNG/JPG, uma por tela.
  Sugestão de nome: `01-captura.png`, `02-historico.png`, `03-consulta.png`, etc.
- **Código do protótipo** (se o Claude Design gerou HTML/React): salve em `design/code/`.
- **PDF:** pode salvar o arquivo aqui na raiz de `design/`.

Depois de colocar os arquivos, é só me avisar ("já coloquei na pasta design") que eu leio tudo
e mapeio cada tela para o modelo de dados e os fluxos.
